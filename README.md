# String-DAG-Cover

This repository has the complementary code to the article "Towards designing Therapeutic Oligonucleotides on Pangenome
Graphs: Complexity and Algorithms" submitted to RECOMB 2027

## Installation

The environment currently is only configured for Linux.

Install environment:
```
pixi install 
```

Run script:
```
pixi run python <script>
```
